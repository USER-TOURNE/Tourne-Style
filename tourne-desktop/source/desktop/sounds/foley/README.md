# Foley UI sounds

Short interface cues made with foley (https://usefoley.dev, https://github.com/eakbulut/foley), MIT licensed,
exported as 16-bit 44.1 kHz WAV. Built into Tourne Desktop by Build-TourneDesktop.ps1 (ui-sounds.inc) and
played by desktop/host/ui-sounds.cpp. Each file's name (without .wav) is the name settings and plugins use.
