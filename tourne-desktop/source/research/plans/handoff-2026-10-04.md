## The goal (Tourne's words)

- "Hyprland on Windows": a Windows application that "can modularly place in custom sets to modify the whole shell". Its pieces mimic shell pieces that users can make or share.
- Windows' own taskbar and Start "all off full stop unless we crash". They are only the fallback.
- "Auto theme everything": wallpaper, then palette, then the shell, then other apps (Discord, Chrome, Zen, all browsers, YouTube, "even apps like you, Claude"). All of it palette-matched from launch.
- Every functionality of the Hyprland wiki, made for Windows.
- Resource-efficient, modular, buildable, adaptive to users. No terminal needed for users.

### Tourne Desktop (`desktop/`, see `desktop/README.md`)

- A standalone exe that runs the suite's hook-free parts (taskbar, switcher with tiling and borders) from their unchanged source. Each part goes in its own namespace, with Windhawk's API answered by `host/module-shim.inl`.
- Build on the PC with `.\desktop\Build-TourneDesktop.ps1`. It uses Windhawk's own clang if installed. The result is `desktop\build\TourneDesktop.exe`, about 1.7 MB.
- Config is `%APPDATA%\Tourne\Desktop\tourne.conf`, written Hyprland-style (`key = value`, `group { }`), and applies when saved. `defaults.conf` lists every setting.
- Flags: `--import` (copy the suite's settings), `--install` / `--uninstall` (start with Windows), `--stop`.
- Tray menu: open settings, open defaults, open folder, Style apps, module list, Quit.
- A module enabled in the Windhawk suite is skipped, so a part never runs twice.

### Tourne theme (auto theming step 1)

- Config: `theme { source = off|wallpaper|seed; profile = adaptive|monochrome|muted|vivid|pastel; mode = auto|dark|light; seed = #RRGGBB; contrast = 4.5 }`. Off by default.
- How it runs: Windows rewrites `%APPDATA%\Microsoft\Windows\Themes` on every wallpaper change, including slideshows and Spotlight. The engine watches that folder, reads the picture with WIC on its own thread, and clusters it in OKLab.
- Output: roles go to `HKCU\Software\Tourne\Theme` as DWORD `0xRRGGBB`: Ground, Raised, Line, Edge, Text, Accent, Muted, Dim, Warn, Bad, Accent2, Good. It also writes Source, Profile, Image and MadeFrom, then `Revision`, last. Finally it posts `TourneThemeChanged` to every top-level window.
- Suite side: the `tourneTheme` scheme option in the taskbar and System Icons scheme lists. The Switcher follows it when its style is "scheme". Each part re-reads when it gets the message.
- Checked on Linux with 9 wallpapers in every profile, and all text passes contrast. The swatch sheet is `/mnt/project-files/tourne-theme/palette-test-sheet.png`.

### CSS injector

- Per-app config: `inject.<app>.on`, `.css` (comma list, relative to `%APPDATA%\Tourne\Desktop\css\`), `.exe`, `.restart = ask|always|never`.
- Known apps: discord, discordptb, discordcanary, claude, spotify, slack, obsidian, vscode. Squirrel apps are started from their newest `app-*` folder. Any other app works through `inject.<name>.exe`.
- How it injects:
  - Tourne starts the app with `--remote-debugging-port=<random free port>` and connects over WinHTTP websocket.
  - `Target.setDiscoverTargets`, then it attaches to page and webview targets with `flatten`.
  - For each page: `Page.enable` (needed), `Page.addScriptToEvaluateOnNewDocument` and `Runtime.evaluate`.
  - The style is `<style id="tourne-css">`, kept last in `<head>` by a MutationObserver.
- Live: saving a CSS file restyles open apps (folder watch, 200 ms debounce).
- Palette CSS: `css\tourne\{generic,discord,claude,spotify}.css` is rewritten on every theme change. The Discord, Claude and Spotify variable names are unverified guesses.
- Consent:
  - Turning an app on shows a warning (the app doesn't support this, updates can undo it, and the debug port is reachable by other programs on the PC). Choices are Yes (restart styled now), No (style it next open) or Cancel. Consent is stored in `HKCU\Software\Tourne\Desktop\Values\inject`.
  - An app opened unstyled is spotted by an out-of-context foreground WinEvent, and the user is asked to restart it.
- Checked: the exact scripts and protocol steps on Linux Chromium (apply, survives reload and page styles, live update, remove). Not checked in a real Electron app.

- **Auto theming, later steps** (`TourneSuite auto theming proposal.md`, section 4b has the per-app routes):

  - The remaining own-colour surfaces follow the theme.
  - Shape, material and motion tokens.
  - Sets with undo, plus album-art music mode.
  - Two decisions are still open: the default wallpaper profile (recommended: adaptive) and whether it may change Windows' accent and mode (recommended: yes, as switches that start off). Tourne said go without answering them, so the recommended choices are in use.
