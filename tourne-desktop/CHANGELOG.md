## ❀ Beta build d9e86c2 (October 29, 2026)

Download: [`release/TourneDesktop-d9e86c2.zip`](release/). It pairs with [Tourne'Suite b65](../windhawk-mods/tourne-suite/) for Square Corners.

This is a **beta build**. Everything since the last public download (77a6918) is in it. Items marked **(beta)** are ones I have not checked on screen yet; the rest I have. Back up your settings before you swap it in (Studio > Presets > "Export my look...").

If you're ever left with no desktop to click in, open Task Manager > Run new task and run `"%LOCALAPPDATA%\Tourne\Desktop\bin\TourneDesktop.exe" --panic` (the full line is also in `shell.log`; see Shell mode below).

### ✦ Shell mode

- **Faster start, no Explorer desktop flash.** The parts now start in the order you see them: theme, taskbar, then switcher and system icons, background services last, 100 ms apart (800 ms after a start that crashed, so a crash is still blamed on the right part). In my tests the desktop is up at about 0.3 s and every part by about 1.8 s, down from about 11 s. The watchdog now hides Explorer's desktop as well as its taskbars, so Explorer can't paint over the screen first, and writes how long Explorer took to `shell.log`. Automatic.
- **`--panic`: get Explorer back with one command.** Run `"%LOCALAPPDATA%\Tourne\Desktop\bin\TourneDesktop.exe" --panic` from Task Manager > Run new task. It turns shell mode off, closes Tourne Desktop (or ends it if it won't quit), then shows the hidden Explorer or starts a new one. Shell mode stays off until you turn it on again in Studio. The watchdog prints this command in `shell.log` at every start. (beta)
- **Startup apps start again with Explorer hidden underneath.** With "Windows apps work (Explorer hidden underneath)" on, nothing from the Run keys or the Startup folder started at sign-in. I now start your startup apps myself either way, unless Explorer already did this sign-in, and apps turned off in Task Manager's Startup page stay off. On by default. Studio > Shell mode > "Start my startup apps". Takes effect from the next sign-in.
- **Tray icons survive a restart, and a stand-in tray catches them at sign-in.** Admin programs that add their tray icon right at sign-in (MSI Afterburner, for example) could land in Explorer's hidden tray and never show, and a Tourne Desktop restart lost them the same way. The tray now remembers its icons for the session and puts back those whose programs still run. From sign-in, a stand-in tray collects icons and hands them over once my tray is up (it gives up after 2 minutes). Tourne Desktop's own tray icon also adds itself again once the tray is up. Always on in shell mode, from the next sign-in. (beta)
- **Swap to Explorer's own taskbar and back.** New bind command `explorerbar` puts my bar and tray away and shows Explorer's taskbar in their place (tray icons move across), then swaps back. Empty swaps each time, `explorer` or `tourne` picks one. Binds editor: "Swap Tourne's bar for Explorer's taskbar". Shell mode only.

### ✦ Switcher, Canvas and tiling

- **Canvas: an infinite canvas of live windows** (ported from PrinceWM, MIT). Every window is a live tile you can pan (left drag, with flick), zoom (wheel at the pointer, + and -) and rearrange; tiles keep the places you give them, by app. An app's windows form one stack that opens with a middle click. Drop one tile on another to put both windows side by side on screen. Pin notes (N) and pasted pictures (Ctrl+V), draw in paint mode (D). Keys: arrows move the selection (Shift moves the tile), Enter or Space switches, Esc backs out, W fits all, F fills with the chosen one, C centres it, Z or 0 zooms to 1:1, R lays them out again, Q or Delete closes a window. Print Screen and Win shortcuts go through, so you can screenshot it. **Win+Tab and the overview command now open the Canvas by default**; Mission Control is still a choice. Studio > Views: "Overview (Win+Tab and the overview command)" (Canvas or Mission Control). For Alt+Tab, pick "Canvas (PrinceWM's infinite canvas)" in the "View" row under the view pictures (Alt+Tab stays The list by default).
- **Spiral and Three columns layouts.** Spiral: each window takes a side of the space left, winding inwards. Three columns: main window in the middle, a column each side. Both are in the layout cycle key. Off by default (not the default layout). Studio > Tiling > "Layout" and "Layout on other screens". (beta)
- **Slice and Split screen layouts.** Slice keeps one window (by program, class or title) in a strip along an edge and lays the rest out in what's left; you pick the edge, the strip size and the layout for the rest. Split screen divides a screen into named regions, each with its own share, layout and windows, one per line (e.g. `region = sidebar, 0 0 25 100, verticalStack, Spotify.exe, Discord.exe`). Focus moves and drops follow the regions; the cycle key skips Split screen when no regions are written. Off by default. Studio > Tiling > "Layout", plus the "Slice: ..." rows and "Split screen: the regions". (beta)
- **Write your own tiling layout in Luau.** "Your own layout (a .luau file in the Layouts folder)": a file in `%LOCALAPPDATA%\Tourne\Layouts` gets the screen, gap, main ratio, an options line and the windows, and returns where each goes. The folder is created with three commented examples; saving the file is enough. Layouts run sandboxed (no internet, no files, no plugin API, 40 ms and 4 MB limit); one that fails falls back to columns and logs why. Off by default. Studio > Tiling > "Layout", and "Your own layout: which file". (beta)
- **Where a newly opened window goes.** At the end (as before), first (it becomes the main window), after or before the window you were in, like qtile's new_client_position. Default: At the end. Studio > Tiling > "Where a window that opens goes". (beta)
- **Drop a window on the pager to send it to that desktop.** Drag a window by its title bar onto a desktop's mark: it goes back where it was and is sent there (following it if "Go along with a window sent" is on). The mark under the pointer lights; edge resizes don't count. Off by default. Studio > Taskbar > Desktop keys > "Send a window by dropping it on the pager". (beta)
- **Tiling fixes.** Gaps wider than the room left could give a window an empty or inside-out size, and BSP ran out of room at about a dozen windows on a small screen. Gaps now shrink before a window does, and windows beyond what fits stack over each other like Monocle. Automatic. (beta)

### ✦ Key binds

Key binds are off by default and nothing is bound until you write a line. Studio > Switcher, tiling and borders > Key binds and control > "Key binds".

- **One command language for keys, menu items and tournectl.** New `run` command: several commands in one line separated by semicolons, with waits between them (`200`, `200ms` or `0.2s`; `\;` is a literal semicolon), e.g. `bind = $mod, N, run, workspace 2; wait 200; exec notepad`. The same line works from a script (`tournectl run "..."`, and `tournectl check "..."` shows what it would do without doing it) and as a Tourne Menu item command `tourne:do ...`. A failing step stops the rest. Menu items need "Key binds" and "Let scripts control Tourne (tournectl)" on, and the editor says so. (beta)
- **Tap, double press and hold on one key.** A key can have a plain bind, a double-press bind (`bindk`) and a hold bind (`bindo`) together; a double press runs only the double-press action. New rows "Double press time (ms)" (300) and "Hold time (ms)" (500); `bindo800`-style lines still set their own hold time. (beta)
- **Act on the window under the pointer.** Binds can name `hovered` (or `mouse`) as the window: the app window under the pointer, never the desktop, a bar or my own windows. `maximize` and `fullscreen` take a window argument. `minimize, hovered` pressed again in the same spot brings back the window it just minimized. (beta)
- **monocle, tileall and tileothers.** `monocle` gives one window its whole tiling area and takes it out of the tiling (the others close up); a second press puts it back in its tile. `monocle, tileothers` tiles the screen's other windows behind it. `tileall` tiles every window on the screen (floating ones too) and resets the main share to half. (beta)
- **Tap a modifier on its own.** A lone modifier can be a bind's key, Hyprland style (`bind = SUPER, SUPER_L, launcher`; also WIN, SHIFT_R, ALT_L...). A Win or Alt tap that runs a bind no longer also opens Start or an app's menu bar. (beta)
- **Open system flyouts from a bind.** `flyout NAME` opens the per-app volume mixer, notifications, network, power, bluetooth, devices, brightness, VPN or security; running it again closes it. Binds editor: "Open a system flyout" (e.g. `flyout mixer` for Win+A).

### ✦ Taskbar and Start

- **Fix: Dynamic shyness never hid the bar with a large tolerance.** The tolerance was taken off every side, so more than half the bar's thickness left nothing. It now counts only from the bar's screen-facing side. Dynamic shyness is off by default, tolerance 8 px. Studio > Taskbar > "Dynamic shyness", "Shyness tolerance (px)".
- **Switching to a minimised admin window restores it.** Clicking a minimised admin window (Task Manager, for example) on the taskbar or in the switcher now brings it back up instead of Windows blocking it. Automatic. (beta)
- **Tray icons that change id each run keep their place.** Programs like MSI Afterburner and HWiNFO give their icon a new id every start, so an icon you put in the overflow or a tray folder came back loose. An icon with no place of its own now takes the place its program's other icons agree on. Automatic. (beta)
- **Clicks in the bar's gaps reach Tourne'Table when it runs as a Windhawk mod**, as they already did with the built-in Table. Other programs' windows still don't get clicks through the gaps. Automatic. (beta)
- **Start: your own Apps folder takes in the packaged apps.** If your Start Menu has your own folder called Apps, All Programs puts the packaged apps in it instead of a second Apps folder; your shortcut wins over an app of the same name and your sort order applies. Start's icons also redraw right away when Tourne'Icons changes icons. On by default. Studio > Taskbar > Start Menu > All Programs: "Display Modern Apps in a folder". (beta)

Automatic in the desktop's menu in Tourne's look (Studio > Shell mode > "The desktop's right-click menu in Tourne's look", off by default) and in the Tourne Menu (Studio > Taskbar > Tourne Menu, off by default). - **Print Screen keeps working.** The Print Screen hook now runs on its own thread and is taken again every minute, since Windows silently drops a slow hook. (beta)
