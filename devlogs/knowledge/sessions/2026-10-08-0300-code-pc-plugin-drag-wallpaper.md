What changed:
- `taskbar-host.cpp`: plugin items now have a place among the tray's icons on a horizontal main bar. `PluginSlots()` puts each before the first tray icon ranked after `plugin:<key>` in the saved tray order (`kTrayOrderValue`); one with no saved place goes first, as before. `PlaceTray` lays them out by slot and fills `g_trayVisual` (the tray's keys as laid out), which `SaveTrayOrder()` now starts from. Dragging: press on a plugin item, move past the drag threshold, and it follows the cursor (`DragPluginItem`); let go on the bar to keep the place, off it (or capture lost) to put it back (`EndPluginDrag`). Not covered: vertical bars (plugins stay one block first) and dropping a plugin into the overflow flyout.
- `desktop/host/desktop-host.cpp`: a wallpaper manager. The desktop's menu (Tourne's look, `shell.desktopMenu`) gets a Wallpaper submenu on the empty space: Choose a picture... (a file dialog), Next picture (by name in the folder, or shuffled), the last 8 others (`HKCU\Software\Tourne\Desktop\RecentWallpapers`, REG_MULTI_SZ; the chosen original in `Wallpaper`), and Placement (Fill, Fit, Stretch, Tile, Center, Span). Set through `IDesktopWallpaper`, else `SystemParametersInfo` with WallpaperStyle/TileWallpaper, on a thread of its own; the desktop reloads when it's done unless Windows' change notice got there first. Commands are kDv 60, 61, 70+ and 80 + DESKTOP_WALLPAPER_POSITION (same numbers in `desktop-menu.cpp`).
- Slideshow: `shell.wallpaper.minutes` (0 = off, the default), `shell.wallpaper.folder` (empty: the folder of the one showing), `shell.wallpaper.shuffle`. A timer on the desktop window, re-armed after each change and when settings change (`DesktopHostSettingsChanged`, called from `ShellApply`).
